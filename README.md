# Сколько на самом деле стоило электричество с Молдавской ГРЭС

Разбор Владимира Тернавского: цена закупки электроэнергии у Молдавской ГРЭС
за 2010-2024 годы, газовый долг левого берега и стоимость киловатт-часа
в нескольких сценариях.

**Страница:** https://vladimirternavschi-collab.github.io/mgres-real-price/

## Что в репозитории

| | |
|---|---|
| `index.html` | вся страница одним файлом: разметка, стили, скрипты, шрифт в base64 |
| `data.json` | все числа графиков и весь реестр фактов для таблицы поиска |
| `og-image.png`, `favicon.svg` | превью для соцсетей и иконка |
| `raschet/` | расчётный модуль: код, промежуточные таблицы, реестр фактов |

## Проверить расчёты

```bash
cd raschet
pip install pandas openpyxl
python run_all.py
```

Скачивать первичные документы для этого не нужно. Подробности, список
допущений и объяснение семи предупреждений при прогоне - в
[raschet/README.md](raschet/README.md).

## Откуда данные

768 фактов, у каждого указаны файл-источник, точное место в нём (страница,
таблица, пункт), формула и статус: из источника, вычислено, оценка или
допущение. Полный реестр в `raschet/REESTR_FAKTOV.csv` и в таблице на самой
странице, где имя источника в каждой строке ведёт прямо на нужный документ.

Первоисточники выложены целиком:
https://drive.google.com/drive/folders/17DhxiuW7cDTYftpHJIWCPSOCWppaFyus

Это 58 файлов: 17 годовых отчётов ANRE за 2009-2025 годы, постановления
регулятора о тарифах, статистические ежегодники Приднестровья, договоры
«Энергокома» с МГРЭС за 2022 год, выгрузки Национального бюро статистики,
данные UN Comtrade и Ember, приложения к закону о бюджете Приднестровья.

## Что эти данные не доказывают

Список ограничений есть в подвале самой страницы и подробнее в
[raschet/README.md](raschet/README.md). Коротко: удельный расход газа это
норматив, а не измеренный факт; доля 43,4 процента посчитана по объёмам за
2010-2020 годы и перенесена на весь долг как оценка; теплотворность газа
остаётся допущением; румынская биржевая цена на графике это мера стоимости,
а не упущенная возможность.

## Технические решения

Страница не обращается ни к одному стороннему домену: шрифт вшит субсетом
в base64, данные вшиты, графики нарисованы вручную на SVG без библиотек.
Работает с отключённым JavaScript: в каждый график вложен заранее отрисованный
SVG. Анимаций, привязанных к прокрутке, нет намеренно.

Страница собирается скриптами из `raschet/sait/`, руками её не правят.
