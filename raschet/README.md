# Расчётный модуль

Здесь лежит всё, чем посчитаны числа на странице. Код, промежуточные таблицы
и реестр фактов, где у каждого числа указан источник, страница и формула.

## Как запустить

```bash
cd raschet
pip install pandas openpyxl
python run_all.py
```

Первичные документы для этого **не нужны**. Они весят больше сотни мегабайт
и в репозиторий не положены, зато результат их разбора лежит в `data/*.csv`.
Модуль это видит и считает по готовым таблицам.

Ожидаемый итог:

```
Итог проверок: OK 61, WARN 7, FAIL 0
Реестр фактов: REESTR_FAKTOV.csv - 768 записей
```

Если хотите пересобрать таблицы в `data/` с нуля, из самих PDF и Excel,
скачайте папку с первоисточниками и укажите путь:

```bash
MGRES_SRC=/путь/к/папке python run_all.py
```

Проверено: результат при этом получается тот же, до последнего знака.

## Из чего состоит

| Файл | Что делает |
|---|---|
| `config.py` | пути и настройки |
| `normalize.py` | раскладывает первичные документы в `data/*.csv` |
| `convert.py` | единицы измерения, курсы, коэффициенты |
| `calc.py` | все расчётные функции |
| `checks.py` | автопроверки, в том числе сверка с контрольными значениями |
| `run_all.py` | весь конвейер одной командой |
| `data/` | 18 промежуточных таблиц, разобранных из первоисточников |
| `sait/` | скрипты сборки самой страницы |
| `REESTR_FAKTOV.csv` | 768 фактов: значение, единица, период, файл, точное место, формула, статус |
| `RESULTS.md` | человекочитаемая сводка всех расчётов |

## Статусы в реестре

- **из_источника** - число взято из документа как есть;
- **вычислено** - получено формулой из чисел со статусом «из источника»;
- **оценка** - косвенный расчёт там, где прямых данных нет;
- **допущение** - в расчёт заложено предположение, оно указано в формуле;
- **требует_проверки** - в исходных данных есть признаки брака, в итоговые
  суммы такие записи не включаются.

## Семь предупреждений при прогоне

Они не ошибки, а известные расхождения, которые оставлены видимыми намеренно.

1. **Договор D7, расхождение 7,24 доллара** - округление в тексте самого договора.
2. **НБС против ANRE, 2018: +16,5 %** - выброс в ряду Национального бюро
   статистики. Третий источник, годовой отчёт ANRE, сходится с Госстатом
   Приднестровья до 0,004 %, значит ошибается ряд НБС.
3. **НБС против ANRE, 2021 и 2022** - разная методика: НБС считает физические
   поставки, ANRE закупки лицензиатов.
4. **Двадцать значений вне исторического диапазона** - в основном экспорт и
   импорт электроэнергии в годы, когда они менялись в разы. Проверено вручную,
   это реальные скачки, а не опечатки.
5. **Электробаланс Приднестровья за 2011 год сходится с расхождением 1,6** -
   при объёме около трёх тысяч миллионов киловатт-часов это пять сотых процента.

## Что заложено допущениями

Это места, где расчёт опирается на предположение. Каждое помечено в реестре
статусом «допущение» и указано в формуле.

**Удельный расход газа 0,3047 кубометра на киловатт-час.** Это норматив,
утверждённый правительством Приднестровья на 2016 год, а не замер. По
определению самой инструкции это верхняя допустимая граница. Расчёт прогоняется
и по вилке от 0,27 до 0,36, результаты есть в `RESULTS.md`.

**Теплотворность газа 34,2 мегаджоуля на кубометр.** Протокола с фактическим
замером найти не удалось, взято справочное значение.

**Доля 43,4 процента.** Посчитана по объёмам газа за 2010-2020 годы и
перенесена на весь долг. Это оценка, а не строка из документа.

**Цена станции 0,073 доллара за киловатт-час** в сценариях себестоимости.
Это не маржа и не себестоимость, а цена, по которой станция фактически
продавала электроэнергию по договору 489-22 в декабре 2022 года, когда газ
доставался ей даром. Мы принимаем её за нетопливную часть цены и в сценариях
с платным газом добавляем топливо сверху.

Отсюда следует одна вещь, которую лучше сказать самим. Первый сценарий, где
газ бесплатный, даёт 292 лея за сто киловатт-часов. Если взять не декабрь
2022 года, а последний контракт 2024 года (66 долларов за мегаватт-час) и не
добавлять транспорт газа, выйдет 269 лей. Разница в 23 лея раскладывается
ровно на два слагаемых: 12 лей на выбор года договора и 11 лей на транспорт.
На выводы это не влияет, потому что оба числа далеко ниже любого сценария с
платным газом, где выходит от 456 до 661 лея.

**Накопленная скидка на газ сложена за тринадцать лет, а не за весь период.**
С 2011 по 2020 год Молдова не подавала данные в таможенную базу ООН, и цен
импорта газа за эти годы нет ни у кого. Год 2016 исключён отдельно: количества
в отчётности занижены примерно в семь раз.

**Выгода и долг посчитаны по разным основаниям.** Выгода по всему газу,
который покупал правый берег. Долг по газу левого берега, сожжённому на
электричество. Это сопоставление итогов одних и тех же отношений с одним
поставщиком, а не вычитание внутри одного счёта.

## Чего здесь нет

Приказы Министерства регионального развития Приднестровья о нормативах расхода
топлива известны по цитатам в статистических ежегодниках. Текстов самих
приказов найти не удалось.

Длинный ряд цен поставки электроэнергии потребителям с 1999 года в отчётах
ANRE существует только как картинка графика, без таблицы под ней. Поэтому за
2011 и 2013-2016 годы на графике наценки пусто.

## Лицензия

Код и реестр фактов можно брать и использовать свободно. Первичные документы
принадлежат их издателям, ссылки на все есть в подвале страницы.
